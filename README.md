# DSA 🧠

A collection of my Data Structures & Algorithms solutions from **LeetCode** and **GeeksforGeeks**, solved in **Python**.

Each problem lives in its own folder, named `<LeetCode-problem-number>-<problem-slug>`. Commits to this repo are made automatically by the **[LeetHub](https://github.com/arunbhardwaj/LeetHub-2.0)** browser extension whenever I submit an accepted solution on LeetCode — it pushes the code and problem statement together, so history stays in sync with what I've actually solved.

---

## 📁 Repo Structure

```
DSA/

│   └── reverse-integer.py

│   ├── README.md

```

Every folder = one problem, auto-generated on submission. Folder names are kept as LeetHub creates them so they stay searchable and sorted roughly by problem number.
